# Console Record Management System

## Project Description

This is a simple console-based Student Record Management System made using Python. It allows the user to add, view, search, update and delete student records.

The records are stored in a JSON file so that the data is available even after closing the program.

## Features

- Add student
- View students
- Search student
- Update student
- Delete student
- File storage
- Basic exception handling
- Menu-driven program

## Concepts Used

- Python variables and data types
- Lists and dictionaries
- if, elif and else
- for and while loops
- Functions
- Exception handling
- File I/O
- JSON
- Menu-driven application

## Files

- `main.py` - Main Python program
- `students.json` - Stores student records
- `REPORT.md` - Assignment documentation
- `screenshots/` - Add application screenshots here

## How to Run

1. Install Python.
2. Open the project folder in Command Prompt or VS Code terminal.
3. Run:

```bash
python main.py
```
